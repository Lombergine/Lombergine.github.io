# Zero-shot LLM correction on CHSER

A follow-up to *CHSER: A Dataset and Case Study on Generative Speech Error Correction for Child ASR*
(Balaji Shankar, Wang, Zhang, Shi and Alwan, Interspeech 2025).

CHSER reports that zero-shot GPT-4o mini raised child-speech WER from 30.5% to 42.1%.
This repo tests the same prompt with Claude Opus 5.5 on a stratified 600-utterance sample of the test split.

| Condition | Weighted WER (%) | Change vs. Whisper (95% CI) |
|---|---|---|
| Whisper-base.en top hypothesis | 31.4 | |
| Claude, 1-best prompt | 28.9 | -2.5 (-3.5 to -1.6) |
| Claude, N-best prompt | 23.0 | -8.4 (-10.3 to -6.7) |

Write-up: https://lombergine.github.io/chser.html

## Important caveat

The saved outputs in `outputs/` were generated by model instances that each processed 50 utterances
from one corpus in a single context, not by independent API calls. Treat the result as provisional
until `run_claude.py` (one request per utterance) confirms it.

## Files

| File | What it does |
|---|---|
| `sample.json` | The 600 sampled utterances (5 hypotheses, reference, source corpus, index in the test file) |
| `inputs/`, `inputs_1best/` | The blind batches the model saw (no references) |
| `outputs/nbest_all.json`, `outputs/1best_all.json` | Model responses keyed by utterance id |
| `evaluate.py` | Scores the outputs with the CHSER normalization and a second check normalization, bootstrap CIs |
| `results/summary.json`, `results/per_utterance.csv` | All numbers in the write-up |
| `run_claude.py` | Independent per-utterance API run with the exact CHSER prompts (resumable) |
| `score_api.py` | Scores a `run_claude.py` output file |
| `make_report.py` | Builds `chser.html` from `results/summary.json` |

## Reproduce

```bash
pip install jiwer num2words anthropic
python evaluate.py
python make_report.py

export ANTHROPIC_API_KEY=...
python run_claude.py --data sample.json --prompt nbest --out outputs/api_nbest.jsonl
python score_api.py outputs/api_nbest.jsonl
```

Corpus labels: the released `dataset/test/hyp.json` has none. The file splits into contiguous blocks
matching Table 1 of the paper (MyST 11,591; CMU Kids 754; OGI spontaneous 457; OGI scripted 5,795;
OCSC 8,090), and each block's baseline WER matches the published value within 0.6 points.

Data: CHSER test split, from https://github.com/balaji1312/CHSER. Please cite the CHSER paper if you use it.
